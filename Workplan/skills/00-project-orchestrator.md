# Project Orchestrator

## Cuándo usarla

Usa esta skill al iniciar cada sesión, al cambiar de semana/fase o cuando el repo esté en un estado ambiguo.

## Objetivo

Mantener el trabajo alineado con el plan, evitar saltos prematuros y cerrar cada sesión con entregables verificables.

## Checklist

- Leer `Claude.md` y `plan-ejecucion-paso-a-paso.md`.
- Revisar `git status --short`.
- Identificar fase actual y bloqueo principal.
- Convertir la sesión en 3 a 7 tareas concretas.
- Priorizar dependencias: schema antes de ingesta, dedupe antes de escala, SEO antes de launch.
- Al final, reportar qué quedó listo, qué se verificó y qué sigue.

## Output esperado

- Plan corto de ejecución de la sesión.
- Cambios implementados.
- Comandos de verificación ejecutados.
- Riesgos o pendientes explícitos.
