# Design System Builder

## Cuándo usarla

Usa esta skill al crear tokens, componentes UI o pantallas principales.

## Objetivo

Crear una UI premium, clara y reutilizable para descubrimiento y comparación de eventos.

## Componentes mínimos

- `Button`
- `Badge`
- `DataPill`
- `Card`
- `EventCard`
- `EventHero`
- `PriceComparisonTable`
- `SetlistPreview`
- `TourHistoryTimeline`
- `StickyMobileCTA`

## Reglas visuales

- Dark theme fijo.
- Amber como acento, no como color de fondo dominante.
- Syne para display, Inter para body.
- Mobile-first.
- La comparación de precios debe aparecer cerca del hero.
- Evitar textos decorativos que expliquen la interfaz.

## Validación

- Revisar responsive desktop/mobile.
- Confirmar que estados `sold_out`, `presale`, `low`, `available` son claros.
- Confirmar que los CTA no se duplican de manera confusa.
